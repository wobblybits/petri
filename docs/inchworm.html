Run

Body

On the limbed body, n₁ = n₃ + 2 − 2c holds exactly, so each cycle you add buys stiffness by deleting two sensors. Blind interior nodes can never claim themselves, so every head is a leaf and basins are whole subtrees — the watershed can only sit at a junction, which makes it hysteretic for free.

A spring net has no resistance to bending, so a U with kb = 0 unfolds into a line within a few gait cycles. And at degree ≤ 3 no body is ever generically rigid past n = 6 (3n/2 edges against the 2n−3 needed), so the angular springs are the entire shape-holding mechanism at every size.

Random cubic graphs are expanders — no bottleneck, no head or tail. Expect them to be much worse bodies than the chain. That contrast is the experiment.

Head field

Each node relays a claim — the source's live reading, the graph distance to it, and which node it is — and keeps the cheapest, where cost(d) = γd₀(d/d₀)p. A head is a node that claims itself, so the head count is exact, not a threshold.

At p = 1 the criterion is purely local: a node is a head unless one of its edges points within arccos(γ) of the food — a 70° cone at γ = 0.35. So any segment lying sideways to the food becomes a head, and most heads are body curvature rather than real lobes. Every body here averages 2–5 of them.

p ≈ 2 is what separates a lobe from a wiggle. One hop then costs γd₀(ℓ/d₀)p, far less than γℓ, so the local threshold tightens to ~85° and spurious heads vanish — while long relays cost more, so genuine extremities keep their own basin. On the U this turns a scatter of 1–4 heads into a stable 2 at almost every food bearing. Note the γ ≥ 1 identity holds at p = 1 only.

Relaying the source rather than a combined value means the field cannot latch — every source re-asserts its live reading each step, so the leak this needed in the scalar version is gone. μ gives the incumbent claim a margin, which is what steadies the watershed.

Gait

Θ = —  ·  u = (s−m)/(M−m) ∈ [0,1], normalised from the head and tail fields alone — no node needs the body's size. No constant term: a uniform shift of θ is pure gauge.

“Set wave θ” imposes a hand-built traveling wave — from graph distance in free mode, from ρ in profile mode. Run it with learning off first — if that doesn't locomote, the physics is wrong, not the learner.

Sensing

Each node reads only its own scalar distance to the food and its neighbours'. Steering is φ̇ += κ(s − ŝ) + κt(s − s̄) — a phase nudge, never a direction. Both terms advance the phase of a node that is worse off: farther than its neighbours, or receding.

Flip κ negative and the body reliably marches away from the food. The correct sign depends on the gait's chirality, so κ is not independent of θ — it's the cheapest demonstration in here that these have to be learned jointly.

Learning

All parameters are dithered simultaneously with independent ±1 signs. Each node demodulates the shared reward against its own sign, so credit assignment costs one broadcast scalar. Timescales must stay separated: learning ≪ dither ≪ gait.

Ablation

Kurin et al. found a star carrying no morphological information matched the true morphology. Physics always uses the real body; this changes only who talks to whom.

Display

Node hue is its learned phase offset θ — a cyclic quantity, so a hue circle. Node size and brightness are its live grip.
